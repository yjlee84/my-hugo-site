# Yongjai Lee — Professional Portfolio

This repository contains the source code and content for my professional website. It presents my background, CV, and selected projects in economics, data analysis, and automation.

The site is built with Hugo using a customised PaperMod theme. Content is written in Markdown, with custom layouts and styling for project pages. Netlify builds and deploys the production site automatically whenever changes are pushed to the main branch on GitHub.

Visit the live website: [yongjailee.netlify.app](https://yongjailee.netlify.app)
